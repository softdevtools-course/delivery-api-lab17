# Учебная лабораторная: API службы доставки

Небольшое FastAPI-приложение для практики REST API. Для каждого студента создаётся отдельная учебная сессия на 24 часа с персональными отправлениями и прогрессом четырёх заданий. Данные хранятся в SQLite.

## Запуск локально

Требуется Python 3.12 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
uvicorn delivery_lab.main:app --reload
```

Откройте <http://127.0.0.1:8000/docs>. База по умолчанию создаётся в `delivery.sqlite3` в текущем каталоге. Её путь можно изменить переменной `DELIVERY_LAB_DATABASE`. Максимальный размер тела запроса по умолчанию — 64 КиБ; для настройки используйте `DELIVERY_LAB_MAX_BODY_BYTES`.

## Работа студента

1. На странице `/docs` заполните фамилию, имя и учебную группу и нажмите «Получить токен».
2. Скопируйте выданный токен. Токен показывается только при регистрации и остаётся в памяти текущей страницы; обновление страницы его не сохранит.
3. В панели заданий виден личный прогресс. В Swagger UI ниже уже используется тот же токен.
4. Выполните четыре сценария с помощью описания API и панели «Try it out»: отмена отправления, просмотр статуса и отслеживания, изменение доставки и создание отправления в выбранный ПВЗ.
5. Повторная регистрация создаёт новую независимую сессию. Старый токен действует до конца своего 24-часового срока, но прогресс не переносится.

Список ПВЗ Чебоксар находится в API. В учебной базе заведены адреса: ул. Гузовского, 16; ул. Водопроводная, 22; ул. Ленинского комсомола, 23к3.
